# Engineering documents

This directory contains the maintained engineering documents for Local Civic Issue Tracker.

| Directory | Purpose |
|---|---|
| `srs/` | Software Requirements Specification and its selected submission versions |
| `spmp/` | Software Project Management Plan and its selected submission versions |
| `adr/` | Numbered Architecture Decision Records, one significant decision per record |

The current SRS is **v1.0, Draft for team review**: [editable DOCX](srs/LocalCivicIssueTracker_SRS_v1.0.docx) and [PDF](srs/LocalCivicIssueTracker_SRS_v1.0.pdf). It expands the [last submitted SRS, v0.2](srs/LocalCivicIssueTracker_SRS_v0.2.pdf), which is retained unchanged. Creation of v1.0 does not establish team approval or submission.

Keep editable document sources and selected PDF submission exports together in the relevant directory. Record document versions, status and revision history explicitly. Reference the actual submitted baseline when preparing an update.

Add design descriptions and verification documents here when they are prepared. Preserve ADR identifiers and decision history; distinguish proposed, accepted and superseded decisions. Do not treat a proposed design or planned test as an approved decision or completed verification.

Private working notes, course templates and reference materials, imported records, experiment outputs and archived prototypes remain in the ignored `.local/` directory. Shared engineering documents must stand on their own and must not depend on machine-specific paths or private working-note links.
